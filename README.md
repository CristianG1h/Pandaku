# Pandaku

Sitio estático de una cronología personal, con páginas para distintos momentos y una galería de imágenes y animaciones. Está hecho con HTML y CSS.

Abre `index.html` para entrar. La navegación enlaza las secciones de la cronología. Conserva juntas las páginas y las carpetas `css/` e `img/` al mover el sitio.

Para reutilizar el diseño, usa imágenes propias o con autorización de las personas que aparezcan en ellas.
